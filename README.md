# Proyecto de Gestión

## Descripción
Este proyecto permite gestionar registros mediante un sistema de opciones que incluyen registrar, editar, eliminar y visualizar datos. Está desarrollado en Python y organiza su funcionalidad en módulos dentro de las carpetas `funciones` y `opciones`. 

Este proyecto fue realizado en equipo por Luis Talero y Karen Cristancho, quienes colaboraron en el desarrollo de la estructura, implementación de funciones y optimización del código para mejorar la gestión de datos.

## Estructura del Proyecto
```
Proyecto_Git_Talero_Luis_Cristancho_Karen-main/
│-- main.py                   # Archivo principal del proyecto
│-- info.json                 # Archivo de configuración
│-- funciones/                # Contiene funciones globales
│-- opciones/                 # Módulos para registrar, editar, eliminar y visualizar datos
│   ├── registrar.py
│   ├── editar.py
│   ├── eliminar.py
│   ├── visualicacion_lista.py
```

## Requisitos
- Python 3.x

## Instalación y Ejecución
1. Clona o descarga el repositorio.
2. Asegúrate de tener Python instalado.
3. Ejecuta el archivo principal:
   ```sh
   python main.py
   ```

## Funcionalidades
- **Registrar**: Permite agregar nuevos datos.
- **Editar**: Modifica registros existentes.
- **Eliminar**: Borra datos seleccionados.
- **Visualizar**: Muestra la lista de registros.
